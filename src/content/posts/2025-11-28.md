## 强化学习基本概念

- state 状态：环境在某一时刻的具体情况，通常用一个向量来表示
- action 动作：智能体在某一状态下可以采取的行为选择
- reward 奖励：智能体在采取某一动作后从环境中获得的反馈信号，表示该动作的好坏
- policy 策略：智能体根据当前状态选择动作的规则或函数，通常表示为 $\pi(a|s)$，即在状态 $s$ 下选择动作 $a$ 的概率
- trajectory 轨迹：智能体在环境中经历的一系列状态、动作和奖励的序列，通常用于训练和评估策略
- return 回报：从某一时刻开始，智能体在未来所获得的累计奖励，通常表示为折扣回报 $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$，其中 $\gamma$ 是折扣因子 
- value function 价值函数：用于评估某一状态或状态-动作对的长期回报预期，常见的有状态价值函数 $V(s)$ 和动作价值函数 $Q(s, a)$
  - 状态价值函数 $V(s)$：表示在状态 $s$ 下，智能体遵循某一策略 $\pi$ 时，未来预期的累计回报
  - 动作价值函数 $Q(s, a)$：表示在状态 $s$ 下采取动作 $a$，然后遵循策略 $\pi$ 时，未来预期的累计回报
- advantage function 优势函数：衡量某一动作相对于平均水平的好坏，定义为 $A(s, a) = Q(s, a) - V(s)$
- model 模型：对环境动态的预测，描述了在给定状态和动作下，环境如何转移到下一个状态以及获得的奖励
- episode 回合：从初始状态到终止状态的一系列状态-动作-奖励序列
- exploration vs. exploitation 探索与利用：智能体在选择动作时需要在探索新动作（以获取更多信息）和利用已知动作（以最大化奖励）之间进行权衡
- discount factor 折扣因子：用于计算未来奖励的现值，通常表示为 $\gamma$，取值范围在 $[0, 1]$ 之间

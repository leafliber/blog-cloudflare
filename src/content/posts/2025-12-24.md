## 设置

在使用Git进行版本控制时，设置全局的用户名和邮箱是非常重要的，因为这些信息会被记录在每次提交中，帮助识别提交的作者。以下是在Git中设置全局用户名和邮箱的步骤：

1. 打开终端（Terminal）

2. 设置全局用户名：

```bash
git config --global user.name "你的用户名"
```

3. 设置全局邮箱：

```bash
git config --global user.email "你的邮箱@example.com"
```

4. 验证设置是否成功，可以使用以下命令查看当前的全局配置：

```bash
git config --global --list
```

## 修改

如果需要修改已经设置的用户名或邮箱，只需重复上述步骤，使用新的用户名或邮箱即可

## 针对某个仓库设置不同的用户名和邮箱

可以在**该仓库的目录**下运行以下命令：

```bash
git config user.name "该仓库的用户名"
git config user.email "该仓库的邮箱@example.com"
```
